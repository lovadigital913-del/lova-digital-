Lova Digital — بەڕێوەبردنی وێبسایت بە Supabase

بەشی بەڕێوەبردن لە مینیوی گشتی شاراوەیە. لە مینیوی گشتی دەرناکەوێت؛ لۆگۆی سەرەوە پێنج جار بە خێرایی لێبدە، یان #admin بە کۆتایی ناونیشانی ماڵپەڕ زیاد بکە. خاوەن بە ئیمەیڵ و وشەی نهێنی Supabase دەچێتە ژوورەوە. دەستکاریکردن تەنها بۆ ئیمەیڵی خاوەنی پڕۆژە ڕێگەپێدراوە.

لە بەشی بەڕێوەبردن دەتوانیت نموونەی گرافیک و وێبسایت زیاد، دەستکاری و بسڕیتەوە؛ وێنە بە فایل باربکەیت؛ جۆری لیستی نوێ دروست بکەیت؛ هەروەها پلاتفۆرمی پەیوەندی لەگەڵ وێنە زیاد، دەستکاری و بسڕیتەوە. گۆڕانکارییەکان بۆ سەردانکەرانی تر لە Supabase پاشەکەوت دەبن.

١) پڕۆژەی Supabase دروست بکە.
٢) Project URL ـەکەت لە Connect dialog وەربگرە؛ ئەوە لە فایلە supabase-config.js دابنێ. Publishable key ـی وێبسایت لەو فایلە دانراوە.
٣) فایلە supabase-setup.sql بکەرەوە و ئیمەیڵەکەت پێشتر لە SQL دانراوە؛ پێویست ناکات بیگۆڕیت. لە Supabase > SQL Editor پەیستی بکە و Run بکە.
٤) لە Supabase > Storage > New bucket، bucket ـێکی Public بە ناوی lova-images دروست بکە. پاشان SQL ـەکە دووبارە Run بکە بۆ ڕێگەدان بە خاوەن کە وێنە باربکات.
٥) لە Authentication > Users هەژماری خاوەن بە هەمان ئیمەیڵ و وشەی نهێنی زیاد بکە. چوونەژوورەوە بە ئیمەیڵ/وشەی نهێنی چالاک و Sign ups ناچالاک بکە.
٦) index.html، logo.png، supabase-config.js و supabase-bridge.js بخە سەر هۆستینگ، لە فۆڵدەری سەرەکیی وێبسایت (لە InfinityFree ناوی htdocs ـە). ZIP بەخۆی ناخرێتە ناو Supabase.
٧) ماڵپەڕەکە بە HTTPS بکەرەوە و بەستەری بەڕێوەبردن بکەرەوە: https://ناونیشانی-ماڵپەڕەکەت/#admin . پاش چوونەژوورەوە، وێنەکان و لیستەکان بەڕێوە ببە.

تێبینی سەلامەتی: service_role/secret key مەخە ناو فایلەکانی وێبسایت. Publishable key بۆ کۆدی وێبە، بەڵام پاراستنی داتا بە RLS و SQL ـی ئەم پەکێجە دەبێت چالاک بێت.
